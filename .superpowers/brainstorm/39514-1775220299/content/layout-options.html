A — Vertical Cards

Each step is a collapsible card. Fields laid out in a grid inside the card. Editing happens inline within the card. Easy to see one step at a time. Good when chains are long.

B — Vertical Table

All steps as rows in a table, columns are fields. Saved rows are read-only, current editing row has inline inputs. Very compact. Easy to compare steps side-by-side vertically.
