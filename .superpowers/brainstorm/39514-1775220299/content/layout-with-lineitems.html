A — Expandable Cards with Line Items

Each step is a card showing:

  • Step header (company, date, % rate increase input)
  • Summary (rate, total, claim, net)
  • Line items table (quality, weight, orig rate, new rate, amount)
  • Total row showing sum
  • Save/Clear buttons

Pros: Clear breakdown per step, easy to verify calculations, self-contained. Cons: Takes vertical space for long chains.

B — Accordion Table with Collapsible Details

Steps shown as collapsible rows:

  • Collapsed: summary line (company, date, % increase, rate, total, status)
  • Expanded: line items table nested below the summary
  • Saved steps are read-only, current editing step has inline % input

Pros: Compact (collapsed by default), all steps visible at once, save space. Cons: More clicks to expand and verify details.
